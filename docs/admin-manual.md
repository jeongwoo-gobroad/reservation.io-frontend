# 관리자 운영 매뉴얼

이 문서는 컴퓨터 비전문가인 매장 관리자가 실제 운영 중 참고할 수 있도록 쓴 설명서입니다.

## 전체 흐름

1. 판매 전, 판매 일정을 만듭니다.
2. 예약을 받을 준비가 되면 해당 일정을 엽니다.
3. 손님은 카카오 로그인 후 예약합니다.
4. 판매 당일, 손님이 오면 방문 확인에서 QR 또는 수동 코드를 확인합니다.
5. 상품을 제공한 뒤 방문 완료 처리합니다.
6. 영업이 끝나면 당일 영업 마감을 누릅니다.
7. 지나간 날짜 중 마감하지 않은 날이 있으면 관리자 메인에서 날짜별로 직접 마감합니다.

중요:

- 이제 프로그램이 서버 시작 시 자동으로 지난 날짜를 마감하지 않습니다.
- 마감은 관리자가 직접 확인하고 눌러야 합니다.
- 마감하면 오지 않은 손님은 노쇼로 처리됩니다.

## 관리자 메인

### 왜 있나요?

오늘 해야 할 일과 놓친 마감이 있는지 한눈에 보기 위해 있습니다.

### 어떻게 활용하나요?

관리자 로그인 후 첫 화면에서 아래 메뉴로 이동합니다.

- 방문 확인
- 판매 일정 만들기
- 현재 예약 현황
- 노쇼/예약 제한
- IP 밴 관리
- 안내문 관리
- 예약 동의 메시지 관리
- 당일 영업 마감

화면 상단에는 `마감이 필요한 지난 영업일`이 표시됩니다.

### 어떤 영향이 있나요?

마감이 필요한 지난 영업일이 보인다면, 그 날짜는 아직 영업 마감 처리가 끝나지 않은 상태입니다. 날짜별로 확인한 뒤 마감해야 노쇼가 정리됩니다.

## 마감이 필요한 지난 영업일

### 왜 있나요?

서버리스 환경에서는 프로그램이 항상 켜져 있는 것이 아닙니다. 그래서 예전처럼 “프로그램을 다시 켜면 어제 날짜를 자동 마감”하지 않습니다.

대신 관리자가 직접 보고 마감합니다.

### 어떻게 활용하나요?

1. 관리자 메인에서 `마감이 필요한 지난 영업일`을 봅니다.
2. 날짜별로 예약 수와 노쇼 예상 고객 수를 확인합니다.
3. 해당 날짜가 정말 끝난 영업일인지 확인합니다.
4. `마감 처리`를 누릅니다.
5. 확인창에서 “미방문 고객은 노쇼 처리됩니다” 안내를 읽습니다.
6. 정말 맞으면 확인합니다.

### 어떤 영향이 있나요?

- 아직 방문 완료되지 않은 예약은 노쇼가 됩니다.
- 노쇼 횟수는 예약 건수가 아니라 손님별 하루 1회만 올라갑니다.
- 마감된 날짜는 다시 미마감 목록에 나오지 않습니다.
- 이미 마감된 날짜를 다시 마감하려 하면 처리되지 않습니다.

## 당일 영업 마감

### 왜 있나요?

오늘 판매가 끝난 뒤, 방문한 손님과 오지 않은 손님을 정리하기 위해 있습니다.

### 어떻게 활용하나요?

1. 오늘 방문 확인이 모두 끝났는지 확인합니다.
2. 관리자 메인에서 `당일 영업 마감`을 누릅니다.
3. 확인창의 내용을 읽습니다.
4. “오지 않은 고객은 노쇼 처리됩니다”를 이해한 뒤 확인합니다.

### 어떤 영향이 있나요?

- 오늘 예약 중 방문 완료되지 않은 예약이 노쇼가 됩니다.
- 방문 완료된 예약은 그대로 유지됩니다.
- 노쇼 기준을 넘은 손님은 자동 예약 제한될 수 있습니다.

## 방문 확인

### 왜 있나요?

현장에 온 손님이 실제 예약자인지 확인하고, 어떤 상품을 제공해야 하는지 보기 위해 있습니다.

### 어떻게 활용하나요?

1. `방문 확인` 메뉴를 엽니다.
2. QR 스캔을 시작합니다.
3. 손님 휴대폰의 방문 확인 QR을 스캔합니다.
4. QR이 안 되면 수동 코드 12자리를 입력합니다.
5. 화면에 손님 닉네임과 예약 상품이 나오면 확인합니다.
6. 상품 제공 후 `제공 완료`를 누릅니다.

### 어떤 영향이 있나요?

- 제공 완료된 예약은 노쇼로 처리되지 않습니다.
- 최근 확인 내역에 남습니다.
- 실수로 화면을 바꿔도 최근 확인 내역에서 다시 확인할 수 있습니다.

## 최근 확인 내역

### 왜 있나요?

방금 스캔한 손님 정보를 다시 보고 싶을 때 사용합니다.

### 어떻게 활용하나요?

1. 방문 확인 화면에서 최근 확인 내역을 엽니다.
2. 기본 10개가 보입니다.
3. 더 보고 싶으면 5, 10, 20, 30, 50 중 개수를 고릅니다.
4. `이전 n개 더 불러오기`를 누릅니다.

### 어떤 영향이 있나요?

조회 기능이므로 예약 상태를 바꾸지 않습니다.

## 판매 일정 만들기

### 왜 있나요?

손님이 예약할 수 있는 날짜, 상품, 재고, 방문 시간을 미리 정하기 위해 있습니다.

### 어떻게 활용하나요?

1. 판매 날짜를 고릅니다.
2. 판매 일정 이름을 입력합니다. 예: `1차 예약`, `박스 예약`
3. 필요한 옵션을 체크합니다.
4. 방문 시간을 나누어 받는다면 시간을 추가합니다. 예: `14:00`, `14:30`
5. 시간마다 받을 수 있는 최대 손님 수를 입력합니다.
6. 상품 그룹을 만듭니다.
7. 상품명, 총 재고, 1인 제한을 입력합니다.
8. 저장합니다.

### 같은 일자 내 다른 일정과 함께 예약 가능

이 옵션은 날짜 전체가 아니라 일정 하나하나에 붙는 설정입니다.

예:

- `1차 예약`: 함께 예약 가능
- `박스 예약`: 함께 예약 불가

손님이 같은 날짜의 여러 일정을 한 번에 예약하려면, 선택한 모든 일정이 “함께 예약 가능”이어야 합니다.

### 어떤 영향이 있나요?

- 예약을 열면 손님 화면에 나타납니다.
- 재고가 모두 차면 더 이상 예약할 수 없습니다.
- 방문 시간 정원이 차면 그 시간은 더 이상 예약할 수 없습니다.

## 현재 예약 현황

### 왜 있나요?

판매 전 준비 수량과 손님 예약 상황을 확인하기 위해 있습니다.

### 어떻게 활용하나요?

1. 날짜를 고릅니다.
2. 필요하면 닉네임으로 검색합니다.
3. 날짜, 일정, 상품, 방문 시간별 예약을 확인합니다.

### 어떤 영향이 있나요?

조회 기능이므로 예약 상태를 바꾸지 않습니다.

## 노쇼/예약 제한

### 왜 있나요?

예약만 하고 오지 않는 손님을 관리하기 위해 있습니다.

### 어떻게 활용하나요?

1. 노쇼 자동 제한 기준을 정합니다.
2. 영업 마감 후 노쇼 누적 손님을 확인합니다.
3. 필요하면 수동으로 예약 제한을 추가합니다.
4. 잘못 제한된 손님은 해제합니다.

### 어떤 영향이 있나요?

- 제한된 손님은 예약할 수 없습니다.
- 노쇼 횟수는 같은 날짜에 여러 예약이 있어도 1회만 증가합니다.

## IP 밴 관리

### 왜 있나요?

관리자 비밀번호를 반복해서 틀리는 IP를 막기 위해 있습니다.

### 어떻게 활용하나요?

1. IP 밴 목록을 확인합니다.
2. 필요하면 직접 IP를 추가합니다.
3. 잘못 막은 IP는 삭제합니다.

### 어떤 영향이 있나요?

- 밴 IP에서는 관리자 로그인이 막힙니다.
- 이미 관리자 토큰이 있어도 관리자 기능 접근이 막힙니다.

## 안내문 관리

### 왜 있나요?

손님이 로그인할 때 꼭 읽어야 하는 안내를 보여주기 위해 있습니다.

### 어떻게 활용하나요?

1. 안내문을 입력합니다.
2. 미리보기를 확인합니다.
3. 저장합니다.

### 어떤 영향이 있나요?

손님은 로그인할 때 안내문을 확인해야 예약 화면으로 이동할 수 있습니다.

## 예약 동의 메시지 관리

### 왜 있나요?

손님이 예약 버튼을 누르기 전 다시 확인해야 하는 내용을 보여주기 위해 있습니다.

### 어떻게 활용하나요?

1. 예약 전 확인 문구를 입력합니다.
2. 저장합니다.

### 어떤 영향이 있나요?

손님은 예약 직전에 이 문구를 확인해야 예약을 진행할 수 있습니다.

## 문제 상황

### QR이 안 됩니다

- 수동 코드 12자리를 입력합니다.
- 손님에게 방문 확인증 화면을 새로고침해 달라고 안내합니다.
- 오늘 예약인지 확인합니다.

### 예약이 안 됩니다

가능한 이유:

- 재고가 모두 찼습니다.
- 방문 시간이 모두 찼습니다.
- 같은 날짜에 이미 예약했습니다.
- 함께 예약할 수 없는 일정이 섞였습니다.
- 예약 제한된 손님입니다.

### 마감할 날짜가 보입니다

그 날짜가 정말 지난 영업일이고, 더 이상 방문 확인할 손님이 없다면 마감 처리합니다.

마감하면 미방문 고객은 노쇼가 됩니다.
